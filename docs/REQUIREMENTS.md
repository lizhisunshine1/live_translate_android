# 需求说明书（Live Translate）

| 项 | 内容 |
| --- | --- |
| 产品名 | Live Translate（应用显示名，包名 `io.github.ztfang.eye`） |
| 版本基线 | 1.3.5（versionCode 9） |
| 平台 | Android 7.0+，真机（arm64-v8a / armeabi-v7a） |
| 文档性质 | 功能需求说明；技术实现细节见 [RUNTIME_PIPELINE.md](RUNTIME_PIPELINE.md) |

---

## 1. 产品定位

把任意 App 里的外语语音变成看得懂的字幕，并把「听过的东西」沉淀成可复习的学习材料。

三条并行主线：

1. **实时**：悬浮字幕，覆盖在任何应用之上，边听边看。
2. **留痕**：每次收听自动归档语音 + 原文 + 译文。
3. **记住**：点词成难词、按遗忘曲线复习。

---

## 2. 目标用户与场景

| 用户 | 场景 | 关键诉求 |
| --- | --- | --- |
| 外语学习者 | 看无字幕视频、网课、播客 | 看懂 + 事后复习生词 |
| 跨语言沟通者 | 会议、客服通话、语聊 | 实时、低延迟、不打断对方 |
| 内容消费者 | 直播、剧集、游戏剧情 | 浮窗不遮挡、可拖动缩放 |
| 通勤/离线用户 | 无稳定网络 | 识别与词典可离线 |

## 3. 功能需求

### FR-1 悬浮字幕

- 提供唯一总开关；打开后字幕以浮窗形式覆盖在任意应用之上，关闭即结束本次收听。
- 浮窗支持拖动、缩放，位置与大小在重启后保持。
- 显示模式三选一：双语（默认）、仅原文、仅译文。
- 外观可调：字号、背景透明度、主题强调色。
- 浮窗不抢输入焦点，不阻塞被覆盖应用的操作。
- 首次使用需引导授予「在其他应用上层显示」权限。

### FR-2 音频来源

- 两种来源二选一：**麦克风**（听环境/面对面说话）、**应用内声音**（Android 10+，不外放也能翻译）。
- 选应用内声音时，每次开启都需要用户重新确认录屏授权（平台限制），需在界面明确提示。
- 缺少麦克风权限时给出可执行的引导，而非静默失败。

### FR-3 语音识别

- 支持按源语言自动选择识别能力；中文与英文共用同一套中英混说能力，不需要用户二选一。
- 识别结果需自带标点与大小写（中英混说场景同样成立）。
- 静音段不送识别以节省算力；重新出现语音时需回补句首，避免“半个词被吞”。
- 断句规则（对用户可见的行为）：
  - 遇到句末标点收口成一行；
  - 说话中短停顿也允许收口，避免一句话等到长停顿才出；
  - 单句过长时强制断开，防止一行占满浮窗；
  - 同一句重复到达时去重，引擎把半句补全时替换而非新增。
- 未收口的半句以“草稿”形式实时显示，并给出轻量预览译文；收口后转为正式行。
- 识别模型未下载时，开关应自动关闭并提示去下载，不得进入“无声失败”状态。

### FR-4 翻译

- 三种引擎可选：**本地离线**、**云端翻译**、**AI 翻译**。
- 本地离线：完全断网可用，首次需下载语言包；无 Google 服务的设备不可用，需明确提示并建议切换。
- 云端翻译：支持多家服务商，用户填自己的密钥；密钥需加密存储，界面不回显明文。
- AI 翻译：一次调用完成“润色 + 翻译”，按 token 流式上屏；可参考上一句的原文与译文保持术语一致，但不得把上一句内容照抄进译文。
- 语言对不支持时静默跳过，不弹错误；网络或鉴权失败时给出可行动的原因分类（超时/鉴权/端点/其他）。
- 流式输出中断：已上屏内容可保留但需标注“可能不完整”；一个字都没输出时保留原文，不得把空串写入历史。

### FR-5 记录本

- 主界面提供「记录本」入口，带待复习数量角标；四页：本次、历史、难词、复习。
- **本次**：当前或最近一次收听的逐句列表，每句显示时间、原文、译文，可单句回放对应语音片段，可整段回放。
- **历史**：按时间倒序列出所有会话，点入查看全文。
- 归档规则：
  - 一次「打开开关 → 关闭开关」= 一次会话；
  - 会话结束自动保存语音文件与文本快照（起止时间、语种、逐句原文/译文/时间轴）；
  - **文字永不自动删除**；语音默认保留；
  - 录音进行中的会话不可回放、不可删除，需给出提示；
  - 停录后短时间内晚到的译文仍应回填到该会话。
- 删除规则（必须两级）：
  - 点删除先询问“删什么”，**默认项为「只删语音」**（文字保留，难词与复习不受影响）；
  - 「删除整条记录」（语音 + 文字）需再确认一次；
  - 复习页提供一次性清理全部语音的入口，清理后文字照旧可用。
- 数据可导出到电脑（通过系统外置存储目录），用户应知道文件在哪。

### FR-6 点词与词典

- 记录里任意句子的英文单词可点：点到哪个词就取哪个词（按字符位置取值，不是按空格切分），标点、缩写、连字符不得切错。
- 点词弹层给出：单词、音标、中文释义、发音按钮，以及「标记为难词」。
- 词典内置、离线可用，覆盖常用词；未收录的词需明确提示“未收录”，但仍允许标记为难词。
- 支持常见词形还原（复数、过去式、进行时、比较级、最高级、副词、所有格等）。

### FR-7 难词与语境

- 标记难词时自动保存三块语境：该词所在整句、前两句、后两句。
- 同一个词重复标记不产生重复条目。
- 难词卡片展示：词、音标、释义、三块语境、当前阶段、下次复习时间，可发音、可删除、可跳回原句。

### FR-8 复习与提醒

- 新标记的词在短时间内进入复习队列，之后按记忆强度动态拉长间隔（见第 4 章遗忘曲线参数）。
- 复习时四档反馈：忘记 / 模糊 / 记得 / 秒懂；答错回到短间隔重来。
- 连续正确且间隔足够长后标记为「已掌握」，不再打扰。
- 复习页显示今日到期数量、当前卡片进度。
- 可选每日提醒：每天固定时间推送一条通知，点击直达记录本复习页；开关默认关闭，开启需通知权限。

### FR-9 设置

- 界面语言（中/英）、源语言、目标语言。
- 翻译引擎与对应配置（服务商、密钥、AI 端点与模型）。
- 浮窗外观（显示模式、字号、透明度、主题色）。
- 模型管理：查看各识别模型的体积与状态，支持下载、续传、删除。
- 音频来源切换。
- 关于与更新检查（可关闭）。

### FR-10 权限、隐私与合规

- 必需权限：麦克风；可选：通知、悬浮窗、录屏（应用内声音）。
- 所有会话数据默认只存在本机应用私有目录，不上传。
- 用户自备的密钥本地加密存储；云端/AI 引擎仅发送待翻译文本，不发送音频。
- 卸载应用会一并清除本机记录。

## 4. 模型与参数

> 本章只保留模型名称与参数；其余实现细节见技术文档。

### 4.1 语音活动检测（VAD）

| 项 | 内容 |
| --- | --- |
| 模型 | Silero VAD（随包内置，约 643 KB） |
| 采样率 | 16 kHz |
| 窗口 | 512 样本（约 32 ms） |
| 语音判定阈值 | 0.5 |
| 最短静音 | 0.25 s |
| 最短语音 | 0.25 s |
| 最长单段 | 5 s |
| 线程 | 1，CPU |

### 4.2 语音识别模型

| 模型 | 覆盖语言 | 技术形态 | 体积 |
| --- | --- | --- | --- |
| X-ASR zh-en 960 ms（int8） | 中文、英文（中英混说） | Zipformer2 流式 transducer，自带标点与大小写 | 约 161 MB |
| Nemotron 3.5 ASR Streaming 0.6B（320 ms，int8） | 26 种语言（中文/英文仍走上一档） | FastConformer-Hybrid RNNT，支持逐流切换语种 | 约 685 MB |
| 孟加拉语 Vosk 导出版 | 孟加拉语 | zipformer2 流式 | 约 83 MB |
| Vosk 单语小包 | 其余语种兜底 | Kaldi 流式 | 每语言 38~100 MB |

识别参数（对使用体验有直接影响的部分）：

| 参数 | 值 | 影响 |
| --- | --- | --- |
| 采样率 | 16 kHz | 与采集一致，不做重采样 |
| 推理线程 | 2 | 延迟与功耗折中 |
| 解码方式 | 贪心（greedy） | 低延迟优先，不用束搜索 |
| 断句规则 1 | 静音 1.2 s | 长停顿收尾 |
| 断句规则 2 | 停顿 0.6 s | 连读场景主力切句 |
| 断句规则 3 | 单段 20 s | 兜底强制切断 |

### 4.3 翻译模型与参数

| 引擎 | 模型 / 服务 | 参数与说明 |
| --- | --- | --- |
| 本地离线 | Google ML Kit 翻译 | 41 种语言；按语言对下载 30~100 MB 模型；需 Google 服务框架；完全离线 |
| 云端 | 百度 / Google Cloud / Azure / DeepL / Papago | 用户自备密钥；按语言对直连；不支持的语言对静默跳过 |
| AI | OpenAI 兼容接口（内置 gpt-5.1 / gpt-5 / gpt-4o 等）、Anthropic Claude（claude-sonnet-4-6 等） | 温度 0.7（对话接口）/ 0.3（兼容端点）；首 token 超时 15 s；流式上屏节流 100 ms；读超时 30 s |

### 4.4 词典

| 项 | 内容 |
| --- | --- |
| 词源 | ECDICT（裁剪） |
| 规模 | 4 万常用词，约 2.47 MB |
| 字段 | 单词、音标、中文释义 |
| 组织 | 按首字母分片，按需加载 |

### 4.5 遗忘曲线（记忆模型）

| 参数 | 值 |
| --- | --- |
| 算法 | SM-2 变体 |
| 反馈档位 | 忘记(2) / 勉强(3) / 记得(4) / 秒懂(5) |
| 难度系数 | 初始 2.5，区间 1.3~2.8 |
| 新词首次复习 | 10 分钟后 |
| 第 1 次正确 | 10 分钟后 |
| 第 2 次正确 | 1 天后 |
| 之后 | 上次间隔 × 难度系数，起步档 1/3/7/16/35 天，夹 1~365 天 |
| 答错 | 间隔归零，10 分钟后重来，遗忘次数 +1 |
| 加分/减分 | 秒懂 ×1.2、勉强 ×0.8 |
| 掌握条件 | 连续 5 次正确且间隔 ≥60 天 |

## 5. 非功能需求

| 类别 | 要求 |
| --- | --- |
| 延迟 | 从说话结束到译文上屏，网络良好时目标 1~3 s；本地引擎更低 |
| 稳定性 | 单句翻译失败不得中断整条链路；识别失败需有可见提示而非静默 |
| 离线能力 | 识别、词典、本地翻译均支持无网使用（本地翻译受 Google 服务限制） |
| 存储 | 语音约 1.9 MB/分钟，必须提供单条与批量的语音清理入口 |
| 兼容 | Android 7.0+；仅 ARM 真机；小米/HyperOS 需按安装说明处理 |
| 隐私 | 音频不上传；密钥加密；记录仅存本机 |
| 可用性 | 主要操作 3 步内可达（开开关、查记录、点词标难词） |

---

## 6. 范围外（本期不做）

- 语音合成播报（TTS 仅用于单词发音）。
- 多用户/云同步、跨设备记录同步。
- 实时双向同传（仅单向：源语音 → 目标文字）。
- 桌面端/网页端。
- 自动生成学习计划、考试模式。

---

## 7. 验收要点

1. 打开开关能出字幕；关闭后本次会话在「本次」页可见，含原文、译文与可回放语音。
2. 点任意英文词能取到整词，弹层显示音标与释义；查不到时明确提示但仍可标记。
3. 标记一个词后，难词页可见该词及「该句 + 前两句 + 后两句」。
4. 复习页显示到期卡片，四档打分能改变下次复习时间；答错回到短间隔。
5. 记录删除默认只删语音：删后文字、难词、复习进度均不变；选择删整条记录需二次确认。
6. 录音结束不自动删语音；语音占用可在复习页查看并一键清理。
7. 未下载识别模型时开关自动关闭并给出下载引导。
8. 关闭网络仍可查词典、点词、复习已存内容。
