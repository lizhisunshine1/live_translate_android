# 记录本 / 难词 / 复习（新增功能说明）

这次在原有「实时悬浮字幕」之上，补了一套**学习闭环**：听到的每句话都被存档，能回看、能点词标记、能按遗忘曲线复习。

## 1. 数据存在哪

所有内容落在 App 私有目录下的 `records/` 文件夹（等价于“项目根目录”在手机上的位置）：

```
/sdcard/Android/data/io.github.ztfang.eye/files/records/
└── 20261121-193015/           # 一次录音会话（打开浮窗 → 关闭浮窗）
    ├── session.json           # 文本快照：时间、语种、逐句原文 + 译文 + 时间轴
    └── audio.wav              # 该次录音（16k/16bit/单声道）；默认一直保留
```

- **文本永不自动删除**：难词语境、复习卡片都依赖它，只有用户在记录窗口里明确点「删除整条记录」并二次确认才会消失。
- **语音默认保留**：录音结束**不会**自动删 wav（约 1.9 MB/分钟）。语音的删除只发生在用户主动操作里——在记录窗口点删除图标，弹层默认给的就是「只删语音（默认）」，文字原样留下。
- **删除两档**：① 只删语音（默认，删 wav、留 JSON/文字）；② 删除整条记录（语音+文字，需再确认一次）。若想批量省空间，「复习」页顶部显示语音总占用，一键清理全部语音、文字不受影响。

数据库（Room，`eye.db`）只做索引：`tb_session` / `tb_line` / `tb_vocab`。Room 版本 2→3 的迁移只加表、不动原有 `tb_history`，老用户升级历史不丢。

想导出来看，可以：

```bash
adb pull /sdcard/Android/data/io.github.ztfang.eye/files/records
```

## 2. 记录窗口

主界面悬浮开关下方有一个「记录本」小按钮（带待复习数量角标），点开是四页窗口：

| 页 | 内容 |
| --- | --- |
| 本次 | 当前/最近一次会话，逐句原文 + 译文，每句可单独回放那段语音 |
| 历史 | 所有会话列表，点进去看全文；可删语音 / 删记录 |
| 难词 | 标记过的词：音标、释义、所在句、前两句、后两句、复习进度 |
| 复习 | 今天到期的卡片，逐张「忘记 / 模糊 / 记得 / 秒懂」 |

## 3. 点词标记（含语境）

记录里任意一句的英文都是可点的：**点哪个词就取哪个词**（不是按空格切分，标点、缩写、连字符都能正确取整词）。

弹层里给出音标、中文释义、发音按钮，以及「标记为难词」。标记时自动抓取：

- 该词所在的整句；
- 该句**前两句**；
- 该句**后两句**。

存下来的是「语境 + 单词」，复习时先看词、回忆句意，再看释义，比孤立背单词更接近真实听力场景。

## 4. 遗忘曲线（SM-2）

`domain/.../ReviewScheduler.kt`，经典 SuperMemo SM-2 变体：

- 新词：10 分钟后首次进入队列；
- 连续答对：10 分钟 → 1 天 → 按难度系数 `ease` 递增（1.3~2.8）；
- 答错：间隔归零，10 分钟后重来，`ease` 下调，记一次 `lapses`；
- 「秒懂」额外拉长 20%，「模糊」缩短 20%；
- 连续 5 次答对且间隔 ≥ 60 天 → 标记「已掌握」，不再打扰。

每日提醒：AlarmManager 每天 20:30 发一条通知，点开直达记录本（开关在「复习」页，默认关闭）。

## 5. 离线词典

- 词库：`app/src/main/assets/dict/<首字母>.tsv`，由 ECDICT 裁剪出的 **4 万常用词**（约 2.4 MB），字段 `单词 \t 音标 \t 释义`。
- 按首字母分片加载，最多缓存 8 个分片，长句滚动时内存稳定。
- 支持词形还原：`studies → study`、`running → run`、`stopped → stop`、`bigger → big` 等。
- 读音走系统 TTS（离线英文音库），音标直接取词典字段。
- 重新生成词库：`python tools/build_dict.py <ecdict.csv> app/src/main/assets/dict 40000`（ECDICT 遵循其仓库 LICENSE）。
